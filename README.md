# 就活管理アプリ

企業の選考状況、面接で使う質問メモ、説明会や締切の日程をひとつにまとめるWebアプリです。
散らばりやすい就職活動の情報を、企業・質問・日程の3つの画面からすぐに確認できます。

## 主な機能

| 企業 | 質問 | 日程 |
| --- | --- | --- |
| 応募先を選考状況ごとに整理。ログイン情報、メモ、質問、予定も企業ごとにまとめられます。 | 面接やESで使う質問と回答を記録。企業やラベルで分類し、必要なメモをすぐに探せます。 | 面接、説明会、提出期限などを月間カレンダーで管理。日時や色を設定して見やすく整理できます。 |

- インターン／本選考の切り替え、検索、絞り込み、並び替えに対応
- 企業と質問メモは、複数選択してまとめて削除可能
- 新規登録、ログイン、メール確認、パスワード再設定、アカウント削除に対応
- システム設定に合わせてライトモード／ダークモードを切り替え

## 画面イメージ

掲載している企業名、メールアドレス、質問、予定はすべて表示確認用の架空データです。
